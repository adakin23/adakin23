## Projects

### ReelRatings
A cross-platform mobile app (React Native + Expo) that lets users rank movies through head-to-head matchups using a dynamic ELO rating system instead of static star ratings. Users swipe to pick a winner between two films, and rankings adjust over time using a variable K-factor that stabilizes as matchup count grows. Features include Google/Apple auth, smart ELO-based opponent pairing, a personal rankings list, streaming availability via TMDB, Letterboxd import, and a weekly GitHub Actions job that refreshes streaming data automatically.
**Skills:** React Native · Expo · Supabase · TMDB API · GitHub Actions
[![View Project](https://img.shields.io/badge/View_Project-1a1a2e?style=for-the-badge)](https://github.com/adakin23/reelratings)

### Alarm Dashboard
A SCADA alarm monitoring dashboard. The underlying data was exported from Ignition SCADA as SQL-generated CSVs, then processed and visualized in Python and Streamlit. The project serves as a trial run for a practical tool that could be pitched to industrial clients for real-time alarm visibility and prioritization.
**Skills:** Python · Streamlit · SQL
[![View Project](https://img.shields.io/badge/View_Project-1a1a2e?style=for-the-badge)](https://github.com/adakin23/alarm-dashboard)

### NovaRetail
A retail analytics dashboard built in Streamlit, providing sales performance insights and visualizations for a fictional retail business persona.
**Skills:** Python · Streamlit · Pandas
[![View Project](https://img.shields.io/badge/View_Project-1a1a2e?style=for-the-badge)](https://github.com/adakin23/NovaRetail)

### Childhood Instability and Later Outcomes
An independent replication-and-extension study in empirical economics, examining how childhood instability, including foster care placement, family structure changes, and caregiver instability, relates to educational and behavioral outcomes later in life. Built as a reproducible research pipeline using longitudinal survey data, with an emphasis on transparent methodology (regression analysis, fixed effects) over polished visuals.
**Skills:** Python · Pandas · Statsmodels · Econometrics · Causal Inference
[![View Project](https://img.shields.io/badge/View_Project-1a1a2e?style=for-the-badge)](https://github.com/adakin23/childhood-instability-outcomes)
